Qwen3-ASR + CTC 头语音模型（可选，config.toml 里 server.model 设为 "QwenCTC"）：
mkdir qwen-ctc-aiinfra4

# 编码器（int4 量化，30 秒桶）
curl -L -o qwen-ctc-aiinfra4/Qwen3-ASR-Encoder.q4.onnx https://huggingface.co/JazerJu/glm-asr-ctc-bench/resolve/main/qwen-ctc/Qwen3-ASR-Encoder.q4.onnx

# CTC 头（fp16，CPU 推理最快；也可换 .q4.onnx / .q4f16.onnx）
curl -L -o qwen-ctc-aiinfra4/Qwen3-ASR-CTC.fp16.onnx https://huggingface.co/JazerJu/glm-asr-ctc-bench/resolve/main/qwen-ctc-aiinfra4/Qwen3-ASR-CTC.fp16.onnx

# 紧凑词表（base64 原始字节，共 72466 条）
curl -L -o qwen-ctc-aiinfra4/tokens.txt https://huggingface.co/JazerJu/glm-asr-ctc-bench/resolve/main/qwen-ctc/tokens.txt

# 特征提取器配置
curl -L -o qwen-ctc-aiinfra4/preprocessor_config.json https://huggingface.co/JazerJu/glm-asr-ctc-bench/resolve/main/qwen-ctc/preprocessor_config.json

# CTC 头结构信息（config.json）
curl -L -o qwen-ctc-aiinfra4/config.json https://huggingface.co/JazerJu/glm-asr-ctc-bench/resolve/main/qwen-ctc-aiinfra4/config.json

将 qwen-ctc-aiinfra4 文件夹放到软件根目录的 models\ 下
