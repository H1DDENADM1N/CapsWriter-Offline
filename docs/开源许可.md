> 统计口径：以仓库当前工作区实际文件与锁定文件为准（`pyproject.toml`、`uv.lock`、`edit_config_gui/package.json`、`edit_config_gui/src-tauri/Cargo.lock`、`site-packages/`、`edit_config_gui/node_modules/`、`models/`、`runtime/`）。
> 快照时间：2026-10-20。依赖版本随 `uv sync` / `pnpm install` / `cargo build` 变化，再发布前请重新核对。

### FFmpeg 的 GPL 传染性说明

`readme.md:1735-1760` 记录了本仓库 FFmpeg 的完整构建参数（`pushd` 到源码目录后执行的那一段 `./configure`），关键项：

```
--enable-gpl \
--enable-libmp3lame \
--enable-static --disable-shared \
--enable-sdl2 \
--enable-encoder="libmp3lame,f32le,pcm_f32le,pcm_s16le,s16le"
```

- 因启用 `--enable-gpl` 且链接 **libmp3lame（LAME，LGPL-2.1）**，产出的 `ffmpeg.exe` / `ffplay.exe` 整体为 **GPL-2.0-or-later**。
- 它是**独立可执行文件**，本项目通过子进程（`subprocess`）方式调用，不与 Python 进程链接，因此 **GPL 不会传染到本项目自身的 Python/Rust 代码**。
- 但再分发 `ffmpeg.exe` / `ffplay.exe` 时仍须履行 GPL 义务：
  1. 随包提供 GPL-2.0 许可原文（**当前仓库缺失**）；
  2. 提供对应源码的获取方式 —— 本项目可提供 `readme.md` 中的完整 `./configure` 与编译说明，并指向 <https://ffmpeg.org/download.html> 与 <https://ffmpeg.org/legal.html>；
  3. 不得对 `ffmpeg.exe` 施加额外限制。
- 若希望规避 GPL，可改为构建 `--disable-gpl`、去掉 `--enable-libmp3lame`（改用内置 `mp3` 编码器或 PCM/WAV 中间格式），此时 FFmpeg 为 LGPL-2.1-or-later。

## 附录 A：清单复现方法

```powershell
# Python：运行环境中的全部发行版及其许可证
.\.venv\Scripts\python.exe -c @"
import importlib.metadata as m
for d in sorted(m.distributions(), key=lambda x: x.metadata['Name'].lower()):
    md = d.metadata
    lic = md.get('License-Expression') or md.get('License') or ''
    if not lic.strip():
        cls = [v for k, v in md.items() if k == 'Classifier' and v.startswith('License ::')]
        lic = '; '.join(cls)
    print(f\"{md['Name']}\t{d.version}\t{lic.strip()}\")
"@

# 前端：pnpm 内置许可清单
cd edit_config_gui
pnpm licenses list --long

cd edit_config_gui/src-tauri
cargo metadata --format-version 1 |
  ConvertFrom-Json -AsHashtable |
  ForEach-Object { $_.packages } |
  Select-Object name, version, license |
  Sort-Object name | Export-Csv -NoTypeInformation -Encoding utf8 rust-licenses.csv
```
