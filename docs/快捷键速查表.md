# 快捷键速查表
> 🔧 = 可在 `config.toml` 改；🔒 = 写死在源码里。

| 程序 | 快捷键 | 作用 | 可改 |
| --- | --- | --- | --- |
| <img src="../assets/icon/client-icon.ico" width="14" height="14" alt="client"> 客户端 | 按住 `CapsLock` | 录音，松开即输入 | 🔧 |
| | 左 `Shift` + `CapsLock` | 离线翻译成英文 | 🔧 |
| | 右 `Shift` + `CapsLock` | 在线翻译 | 🔧 |
| | 连点两次 `CapsLock` | 临时切简 / 繁 | 🔒 |
| | `Ctrl+Alt+Shift+F1`–`F8` | 切换提示词风格：公文 / 甜蜜 / 社交 / 古诗 / 英文 / 学术 / 客服 / 创意 | 🔧 |
| | `Esc` | 有副光标先收敛；否则隐藏窗口 | 🔒 |
| | 双击托盘图标 | 居中显示 ↔ 隐藏 | 🔒 |
| | `Ctrl` + 滚轮 | 字号放大 / 缩小（5–45 pt） | 🔒 |
| | `Alt` + 点击 | 加 / 减一个副光标 | 🔒 |
| | `Alt` + 拖拽 | 矩形列选 | 🔒 |
| | `Ctrl+Alt+↑ / ↓` | 上 / 下一行同列加光标 | 🔒 |
| | `Ctrl+U` | 撤销最后一个副光标 | 🔒 |
| | `Ctrl+D` | 选中词，再按选中下一个相同 | 🔒 |
| | `Ctrl+Shift+L` | 选中全文所有相同内容 | 🔒 |
| | 方向键 / `Home` / `End` | 所有光标同步移动（加 `Shift` 同步选中） | 🔒 |
| | `Alt+← / →` | 视觉行行首 / 行尾 | 🔒 |
| | `Ctrl+← / →` | 按词跳（中文 jieba 分词） | 🔒 |
| | `Alt+↑ / ↓` | 上移 / 下移当前行 | 🔒 |
| | `Shift+Alt+↑ / ↓` | 向上 / 向下复制当前行 | 🔒 |
| | `Ctrl+Shift+K` | 删除整行 | 🔒 |
| | `Ctrl+/` | 注释 / 取消注释（加 `#`） | 🔒 |
| | `Ctrl+F` / `Ctrl+H` | 查找 / 查找替换 | 🔒 |
| | `Enter` / `Shift+Enter` | 下一个 / 上一个 | 🔒 |
| | `Ctrl+Alt+Enter` | 全部替换 | 🔒 |
| | `Tab` / `Shift+Tab` | 查找框 ↔ 替换框 | 🔒 |
| | 查找栏内 `Esc` | 关闭浮层 | 🔒 |
| | `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | 撤销 / 重做（多光标整体一步） | 🔒 |
| | 任意字符、`Backspace`、`Delete`、`Enter` | 同时作用于所有光标 | 🔒 |
| | `Ctrl+C` / `Ctrl+X` | 矩形列选时复制 / 剪切整块 | 🔒 |
| | `Ctrl+A` / `Ctrl+V` 等 | Qt 原生编辑键 | 🔒 |
| | `Shift` + 悬停「回到底部」 | 按钮翻成「回到顶部」 | 🔒 |
| | 点击「回到底部」 | 滚到最新并恢复跟随 | 🔒 |
| | 左键单击 | 收敛副光标 | 🔒 |
| | 右键单击 | 先收敛再弹菜单 | 🔒 |
| | 中键单击 | 不影响副光标 | 🔒 |
| | 双击文本 | 按词选中（中文 jieba） | 🔒 |
| | 矩形选中 + `Delete` / `Backspace` | 删矩形覆盖的每一行 | 🔒 |
| | `PageUp`/`PageDown`/`Home`/`End`/方向键 | 滚动，同时挂起日志跟随 | 🔒 |
| <img src="../assets/icon/config-icon.ico" width="14" height="14" alt="config"> 配置编辑器 | `Ctrl+F` | 搜索配置项 | 🔒 |
| | `Ctrl+S` | 预览 diff 后保存 | 🔒 |
| | `Ctrl+=` / `Ctrl++` / `Ctrl+-` / `Ctrl+_` | 缩放大 / 小一档 | 🔒 |
| | `Ctrl+0` | 缩放回 100%（仅本次会话） | 🔒 |
| | `Ctrl` + 滚轮 / 触控板捏合 | 缩放，一手势一档 | 🔒 |
| | `Esc` | 关搜索面板 / 关预览对话框 | 🔒 |
| | 搜索面板内 `↑` / `↓` / `Enter` | 选择结果 / 跳到该项 | 🔒 |
| | `PageUp` / `PageDown` | 翻一屏（90% 视口） | 🔒 |
| | `↑` / `↓` | 滚动 80 px | 🔒 |
| | 录制框任意组合键 | 录成 `ctrl + alt + f5` 写入配置 | 🔒 |
| | 录制框 `Esc` | 取消录制，不写入 | 🔒 |
| <img src="../assets/icon/server-icon.ico" width="14" height="14" alt="server"> 服务端 | `Esc` | 隐藏窗口 | 🔒 |
| | 双击托盘图标 | 居中显示 ↔ 隐藏 | 🔒 |
| | `Ctrl+A` / `C` / `V` / `X` / `Z` / `Y` | `QTextEdit` 原生编辑键 | 🔒 |
| <img src="../assets/icon/config-selector-icon.ico" width="14" height="14" alt="selector"> 配置选择器 | `Enter` | 确定（应用配置并问是否重启服务） | 🔒 |
| | `Esc` | 取消关闭 | 🔒 |
| | `↑` / `↓` | 切换配置文件 | 🔒 |
| <img src="../assets/icon/hint_while_recording.ico" width="14" height="14" alt="hint"> 录音提示 | 无 | 由客户端消息驱动，不自带按键 | — |

`ffplay` / `ffmpeg` / `deeplx_windows_amd64` / `runtime\python*.exe` 为命令行或后台程序，无快捷键。
