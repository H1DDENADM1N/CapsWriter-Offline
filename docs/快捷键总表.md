# CapsWriter-Offline 快捷键总表

> 依据源码核对：`start_client_gui.py`（窗口）+ `util/client/multicursor_edit.py`（文本框）、`edit_config_gui/src`（Tauri + Svelte 配置编辑器）。

**标记说明**

| 标记 | 含义 |
| --- | --- |
| 🔧 可改 | 键位写在 `config.toml`，可改文件，也可在配置编辑器的录制框里直接按键录入 |
| 🔒 写死 | 键位写在程序源码里，`config.toml` 改不了 |
| 🌐 系统全局 | 由 `keyboard` 库在操作系统层挂钩，任何程序在前台都生效；客户端窗口关着也生效 |
| 🪟 窗口内 | 由 Qt / 浏览器控件自己处理，只在该窗口有焦点时才生效 |

## <img src="../assets/icon/client-icon.ico" width="20" height="20" alt="client-icon"> 一、客户端 `start_client_gui.exe`

> 本节除最后两组「全局热键」外，键位全部 🔒 写死，🪟 只在客户端窗口有焦点时生效。

### 窗口 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `Esc` | 有副光标时先收敛回单光标；没有副光标时**隐藏窗口**（不退出程序） |
| 双击托盘图标 | 窗口居中显示 / 隐藏来回切换；处于时钟状态时先切回客户端界面 |

### 文本框：多光标编辑 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + 滚轮 | 放大 / 缩小字号（5–45 pt），随时可调 |
| `Alt` + 点击 | 在点击处加 / 减一个副光标 |
| `Alt` + 拖拽 | 矩形列选（多行同一列） |
| `Ctrl+Alt+↑ / ↓` | 在上 / 下一行同列加光标 |
| `Ctrl+U` | 撤销最后添加的一个副光标 |
| `Ctrl+D` | 选中光标下的词；再按一次选中下一个相同内容 |
| `Ctrl+Shift+L` | 选中全文所有相同内容 |
| `↑` `↓` `←` `→` / `Home` / `End` | 所有光标同步移动；加 `Shift` 同步扩展选区（`Ctrl+Home/End` 到文档首尾） |

### 文本框：行与词的移动 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `Alt+← / →` | 跳到当前**视觉行**行首 / 行尾（加 `Shift` 为选中） |
| `Ctrl+← / →` | 按词跳（中文按 jieba 分词，英文按整词；加 `Shift` 为选中） |
| `Alt+↑ / ↓` | 上移 / 下移当前行 |
| `Shift+Alt+↑ / ↓` | 向上 / 向下复制当前行 |
| `Ctrl+Shift+K` | 删除整行 |
| `Ctrl+/` | 注释 / 取消注释涉及的行（加 `#`） |

### 文本框：查找与替换 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+F` | 打开查找栏 |
| `Ctrl+H` | 打开「查找 + 替换」两行 |
| `Enter` | 查找下一个 / 替换当前 |
| `Shift+Enter` | 查找上一个 |
| `Ctrl+Alt+Enter` | 全部替换（只占一步撤销） |
| `Tab` / `Shift+Tab` | 在查找框与替换框之间切换 |
| `Esc` | 关闭浮层，焦点回到文本框 |

### 文本框：编辑与撤销 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Z` | 撤销；多光标编辑一步整体撤回 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| 任意字符 / `Backspace` / `Delete` / `Enter` | 同时作用于所有光标 |
| `Ctrl+C` / `Ctrl+X` | 矩形列选时复制 / 剪切整块文本 |
| `Ctrl+A` / `Ctrl+V` 等 | 沿用 Qt 原生编辑快捷键 |

### 文本框：滚动按钮与鼠标手势 🪟 🔒

| 操作 | 作用 |
| --- | --- |
| `Shift` + 悬停「回到底部」按钮 | 按钮当场翻成「回到顶部」（图标转 180°），点它是跳到最顶部 |
| 点击「回到底部」按钮 | 滚到最新内容并恢复「新日志自动跟随」 |
| 普通左键单击 | 收敛副光标，只保留点击处那一根 |
| 右键单击 | 先收敛副光标再弹菜单；点在自己矩形选区内时保留选区 |
| 中键单击 | 不影响已有副光标 |
| 双击文本 | 按词典分词选中一个词（中文按 jieba 词粒度） |
| 矩形列选中按 `Delete` / `Backspace` | 删除矩形覆盖的每一行（不是只删主光标那行） |
| 矩形列选中用右键菜单剪切 / 删除 | 同样作用于矩形整块 |

> 按钮只在鼠标位于客户端窗口内、且视口不在底部时浮出；鼠标移出窗口它就隐藏。跳到顶部后会**挂起跟随**，新日志不再把视图拽回底部，直到你滚回距底 40 px 以内。键盘滚动键（`PageUp` / `PageDown` / `Home` / `End` / 方向键）同样算「用户主动滚动」，也会挂起跟随。

### 全局热键：录音 / 翻译 🌐 🔧

| 快捷键 | 作用 | `config.toml` 键 |
| --- | --- | --- |
| 按住 `CapsLock` | 录音，松开后识别结果立即输入 | `[client] speech_recognition_shortcut` |
| `Left Shift` + `CapsLock` | 离线翻译为英文 | `[client] offline_translate_shortcut` |
| `Right Shift` + `CapsLock` | 在线翻译 | `[client] online_translate_shortcut` |
| 连续快速轻点两次 `CapsLock`（每次短于阈值） | 临时切换简 / 繁输出 | 无独立键位，由上面的录音键触发；`[client] enable_double_click_opposite_state` 控制该效果是否生效 |

> 这三条由 `util/client/shortcut_handler.py` 在系统层挂钩，不是窗口快捷键。`hold_mode = false` 时改为「点一下开始录音、再点一下结束」的点按模式；连续两次轻点（间隔 < `threshold`，默认 0.5 s）仍是切简 / 繁。配置编辑器里这三项是录制框，直接按键即录入。

### 提示词风格切换热键 🌐 🔧

| 快捷键 | 切换到的风格 | `config.toml` 键 |
| --- | --- | --- |
| `Ctrl+Alt+Shift+F1` | 正式公文校对（official） | `[client.prompt_style] prompt_official_shortcut` |
| `Ctrl+Alt+Shift+F2` | 甜蜜男友式润色（sweetheart） | `prompt_sweetheart_shortcut` |
| `Ctrl+Alt+Shift+F3` | 社交媒体文案（social） | `prompt_social_shortcut` |
| `Ctrl+Alt+Shift+F4` | 古诗创作（poetry） | `prompt_poetry_shortcut` |
| `Ctrl+Alt+Shift+F5` | 英文润色（english） | `prompt_english_shortcut` |
| `Ctrl+Alt+Shift+F6` | 学术论文优化（academic） | `prompt_academic_shortcut` |
| `Ctrl+Alt+Shift+F7` | 客户服务回复（customer_service） | `prompt_customer_service_shortcut` |
| `Ctrl+Alt+Shift+F8` | 创意写作（creative_writing） | `prompt_creative_writing_shortcut` |

> 按一次就把 `prompt_style_selection` 写进 `config.toml`，由 `util/client/hot_update.py` 热更新到运行中的客户端，AI 优化随即使用新风格。留空则该项不绑定。

## <img src="../assets/icon/config-icon.ico" width="20" height="20" alt="config-icon"> 二、配置编辑器 `edit_config_gui.exe`

> 全部 🪟 窗口内、🔒 写死：`config.toml` 里没有编辑器的键位项，改不了。

### 全局 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+F` | 搜索配置项（中文 / 键名 / 拼音 / 首字母） |
| `Ctrl+S` | 预览保存：先看 diff，确认后才写盘 |
| `Ctrl+=` / `Ctrl++` | 缩放大一档（50%–200%） |
| `Ctrl+-` / `Ctrl+_` | 缩小一档 |
| `Ctrl+0` | 缩放回到 100%（不写盘，只对本次会话有效） |
| `Ctrl` + 滚轮 / 触控板捏合 | 放大 / 缩小，一次手势只算一档 |
| `Esc` | 关闭搜索面板 / 关闭保存预览对话框（写盘进行中不可关） |

### 搜索面板内 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `↑` / `↓` | 上下选择搜索结果 |
| `Enter` | 跳到选中项（切页并滚动到该行） |
| `Esc` | 关闭面板 |

### 页面滚动 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| `PageUp` / `PageDown` | 上 / 下翻一屏（视口高度的 90%） |
| `↑` / `↓` | 上 / 下滚动 80 px |

### 录制快捷键的输入框 🪟 🔒

| 快捷键 | 作用 |
| --- | --- |
| 任意组合键 | 录成 `ctrl + alt + f5` 形式写进对应配置项，可直接被客户端解析 |
| `Esc` | 取消录制（不写入值） |

## 四、补充说明

- **可改 vs 不可改**：`config.toml` 能改的只有客户端**全局热键**——录音、离线翻译、在线翻译共 3 条，提示词风格共 8 条，外加下面是「程序模拟发送」的播放器暂停键；其余所有窗口内快捷键都写死在源码里。
- **播放器暂停键（不是给你按的）**：`[client] QQMusic_global_pause_hotkey` / `CloudMusic_global_pause_hotkey` / `PotPlayer_global_pause_hotkey` / `foobar2000_global_pause_hotkey`（默认 `ctrl + alt + f5`–`f8`）🔧 可改，🌐 但它们是**程序替你模拟按下的**：识别开始时把播放器暂停、结束时再发一次恢复。留空则不暂停。还可在 `[client.additional_special_apps]` 段里按「进程名 → { hotkey, name }」自行扩充。
- **只是行为开关、不是键位**：`[client] hold_mode`（长按 / 点按）、`suppress`（是否拦截按键）、`restore_key`（长按后恢复 CapsLock 原功能）、`threshold`（双击判定间隔，默认 0.5 s）。
- **编辑器的录制框**：客户端那 11 条全局热键在配置编辑器里都是录制控件，按一下想要的组合键即可写入 `config.toml`，等价于手改文件。
- 配置编辑器的方向键滚动：焦点在输入框 / 下拉框 / 可编辑区，或搜索面板、保存对话框打开时**不接管**，方向键归控件自己。
- `Ctrl+K` 是配置编辑器早期版本的搜索快捷键，现已改为 `Ctrl+F`。
- 客户端与服务端的 `Esc` 都只是**隐藏窗口**，退出程序请用托盘菜单。
- 客户端弹出的对话框（如「编辑 API Key」）沿用 Qt 默认：`Enter` = 确定，`Esc` = 取消。
- 双击录音键切简繁：只在**繁体转换已产出**时看得出差别；`minimal` 配置里该效果为 `false`，双击不会有变化。
- **图标来源**：各表标题前的图标直接引用仓库里的 exe 图标——`../assets/icon/client-icon.ico`（客户端 / 管理员版客户端）、`../assets/icon/config-icon.ico`（配置编辑器，与 `edit_config_gui/src-tauri/icons/icon.ico` 同一文件）、`../assets/icon/server-icon.ico`（服务端）、`../assets/icon/config-selector-icon.ico`（配置选择器）、`../assets/icon/hint_while_recording.ico`（录音提示）。
- 配置选择器的 `Enter` → OK、`Esc` → 取消属于 Qt 对话框内建行为（第一个按钮自动成为默认按钮），已用 PySide6 离屏实测确认；同样实测：原生 `QTextEdit` 在 `Ctrl` + 滚轮下**不**缩放字号（所以服务端没有缩放快捷键）。
